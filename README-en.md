# Smartphone-Based Emergency Rescue & Accident Detection System

> 🏆 **2nd Prize** – Gia Lai Provincial Science and Engineering Competition 2025 (Embedded Systems Category)

## Overview
An IoT and Mobile Software solution designed to minimize hardware costs for emergency rescue systems. By leveraging a smartphone paired with embedded sensors and Machine Learning logic, the system automatically detects traffic accidents in real-time and triggers emergency calls and location alerts to contacts.

---

## Tech Stack & Tools
* **Mobile Application:** MIT App Inventor (Block-based / No-code Android development)
* **Hardware & Embedded:** Microcontroller, Motion/Impact Sensors, Hardware Modules
* **Intelligence:** Machine Learning model for crash detection logic

---

## My Role & Contributions
This project was a collaborative team effort. My primary responsibilities included:
* **System Testing & Validation:** Conducted real-time testing between the Android mobile application and hardware sensor modules.
* **Hardware-Software Integration:** Assisted in troubleshooting data transmission and logic flow from sensors to the app.
* **Project Documentation & Field Trialing:** Participated in scenario design, system field testing, and preparing demonstration materials for the competition.

> *Note: I focused on system integration, hardware testing, and field execution, rather than writing the core algorithm code independently.*
